### 2.2.1 Система аутентификации (2-3 стр)

**Процесс входа:**

```typescript
// Пример кода для раздела

const login = async (username: string, password: string) => {
  try {
    const response = await fetch('/api/auth/login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ username, password })
    });
    
    const data = await response.json();
    localStorage.setItem('accessToken', data.access);
    localStorage.setItem('refreshToken', data.refresh);
    setUser(data.user);
  } catch (error) {
    setError('Ошибка входа');
  }
};
```

**Защита маршрутов:**

```typescript
const ProtectedRoute = ({ children }) => {
  const { user, loading } = useAuth();
  
  if (loading) return <div>Загрузка...</div>;
  return user ? children : <Navigate to="/login" />;
};
```

### 2.2.2 Управление каталогом (2-3 стр)

**Компонент Home:**
- Загрузка только одобренных (approved) алгоритмов
- Клиентская фильтрация по параметрам
- Поиск полнотекстовый

**Фильтрация:**
```typescript
const filteredAlgorithms = algorithms.filter(algo => {
  const matchesSearch = algo.title.includes(searchQuery) ||
                       algo.description.includes(searchQuery);
  const matchesLanguage = languageFilter === 'all' || 
                         algo.language === languageFilter;
  const matchesType = typeFilter === 'all' ||
                     (typeFilter === 'free' && !algo.isPaid) ||
                     (typeFilter === 'paid' && algo.isPaid);
  
  return matchesSearch && matchesLanguage && matchesType;
});
```
